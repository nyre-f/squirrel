# 小松鼠生活管家 v1.9.50

- “小松鼠人生轨迹”新增按年、按月两级折叠。
- 点击年份气泡可收起/展开整年；展开年份后，可继续点击月份气泡单独收起/展开该月。
- 年份和月份标题会显示该范围内的记录数量，长时间轴更容易快速浏览。
- 只记录到“某年”的节点保留在该年份下的“全年记录”区域，不会被强行归入某个月。
- 折叠状态会随生活管家数据保存，刷新页面后仍保留。
- 使用“跳到时间”时，会自动展开目标年份和月份，再定位到对应位置。
- 原有全屏纵向时间轴、手机上下滑动、电脑空白处拖动、日/月/年三种时间精度、右侧半透明气泡菜单均保留。
- v1.9.49 的日历迁移逻辑继续保留；旧日历已经迁入的人生轨迹不会丢失。
- 数据结构版本升级为 46；IndexedDB、localStorage 镜像、版本快照与外部 JSON 备份机制保持不变。
