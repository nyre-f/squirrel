# 小松鼠生活管家 v1.9.46

## 本次更新：逐级缩放与手动选点打卡

- 足迹地图保持离线运行，不调用在线地图服务。
- 点击省份会直接进入该省的市级地图；点击城市会直接进入区县地图；点击区县进入道路/选点层。
- 全国、省、市、区县、道路层全部支持放大、缩小、复位和拖动浏览，最高 24×。
- 地图浏览和打卡彻底分离：点击地区只负责下钻，不会自动打卡。
- 进入省、市、区县后均可点击“📍 打卡这里”手动记录当前层级。
- 新增“📌 选点”模式：在任何一级地图上手动点击位置放置临时定位针，不会立即保存。
- 临时定位针可修改名称，再点击“📍 打卡选点”才会真正写入足迹。
- 道路层即使不开启选点模式，也可直接点击道路/地标放置临时定位针，再手动确认。
- 打卡记录显示地点、完整层级、精确时间；手动选点还保存坐标。
- 已保存的手动选点会在对应地图层显示小脚印。
- 当前离线道路骨架继续内置北京中心城区、徐州中心城区及少量标志性地点；其他未内置道路的区县仍可在本地选点地图中手动记录位置。
- 修复 IndexedDB 版本兼容：打开数据库时先使用设备上的实际版本，绝不再请求低于现有版本的数据库版本；缺少存储表时才向上升级修复。
- 旧版账本、日历、读后感、阅读记录、足迹和打卡数据均保留并迁移。
