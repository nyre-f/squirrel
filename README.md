# 小松鼠生活管家 v1.9.57

## 新事件 / 扩窝计划
- 新增独立“扩窝计划”模块，用来记录生活和工作中真正遇到的陌生事情。
- 陌生程度分为绿色 / 黄色 / 红色，仅用于回忆当时的陌生程度，不代表好坏。
- 状态支持“还没开始 / 处理中 / 完成了 / 暂时放下”；“暂时放下”不作为失败处理。
- 可选记录事前担心程度 0～100；完成后可选填写实际发生、结果、耗电程度、实际困难和下次经验。
- 完成后只显示温和反馈，不提供完成率、连续天数、失败率、排名或惩罚。
- 首页增加紧凑“扩窝计划”卡片，显示本周新事件数量和最近一条记录。
- 历史按时间倒序，可筛选陌生程度、已完成和暂时放下。
- 支持“我已经会了 🌱”，熟悉后的事件继续保留，但不再计入当前新事件。
- 复盘中的“下次经验”自动汇入经验库，并按工作流程 / 社交 / 生活轻量分类；经验可编辑或删除。
- 新事件名称与旧记录相似时，只在表单内轻提示相关旧经验，不弹窗、不自动判定。
- 提供本周 / 本月轻量回顾，不展示完成率、排名或连续打卡。
- 新事件草稿和复盘支持本机自动保存，所有数据进入现有 IndexedDB、localStorage 镜像、快照和 JSON 完整备份。
- 保留 v1.9.56 的家务暂停、自动更新、手机适配和家务卡片固定操作布局；预算、植物日历、人生轨迹等原有模块逻辑不变。
- 数据结构版本升级为 51。
