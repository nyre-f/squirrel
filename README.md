# 小松鼠生活管家 v1.9.49

- 删除“日历计划本”页面、首页入口和底部日历导航。
- 原底部“日历”位置改为“🌿 轨迹”，人生轨迹成为主要功能入口。
- 首次读取 v1.9.48 及更早版本的数据时，会自动把旧日历记录并入“小松鼠人生轨迹”，随后移除日历模块。
- 同一天的旧日历内容会整理为一个时间轴节点，并保留日期、日历标注、日记正文、待办及完成状态、心情碎碎念、上午/下午/晚上心情颜色和日历打卡痕迹。
- 旧日历中的未来计划也不会丢失，会按原计划日期迁移，并在无原标注时显示为“原日历未来计划”。
- 原有的人生轨迹节点不会覆盖或删除，迁入的日历节点作为额外节点加入。
- 导入旧版 JSON 备份时同样会自动执行日历迁移。
- 人生轨迹仍保持 v1.9.48 的全屏纵向时间轴、手机上下滑动、电脑空白处拖动、日/月/年三种时间精度及右侧半透明气泡菜单。
- 数据结构版本升级为 45；IndexedDB、localStorage 镜像、版本快照与外部 JSON 备份机制保持不变。
