# 小松鼠生活管家：公开部署安全壳

这个版本用于上传到静态网站，不包含私人账目、金额或家务完成历史。

## 文件必须全部放在网站根目录

- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

部署完成后：

1. 用手机 Edge 打开 HTTPS 网址。
2. 等页面加载完成，再打开 Edge 菜单。
3. 选择“添加到手机”或“安装应用”（具体名称可能因版本而异）。
4. 安装后打开应用。
5. 进入“备份”页面，导入单独保存的私人 JSON 备份。

## 重要

不要把“私人初始数据.json”上传到网站或公开代码仓库。
它只应保存在自己的手机、电脑或个人云盘中。
