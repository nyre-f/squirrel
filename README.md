# 小松鼠生活管家 v1.9.26

本版在 v1.9.24 的全部功能基础上完成像素田园风换肤，并新增记梦笔记本。

## 本版重点
- 全站采用原创温暖农场像素风：木牌、羊皮纸、草地、山景、硬边框与像素阴影。
- 首页、日历、记账、家务、记梦、探店、愿望、脑力、居民和备份均统一换肤。
- 居民模块中的动物 Emoji、名字、关系、养成属性和历史数据全部保持不变。
- 底部导航顺序为：首页、日历、记账、家务、记梦、探店、愿望、脑力、居民、备份。
- 新增记梦笔记本：可选择日期、切换前后一天、点击大型笔记本记录梦境。
- 梦境支持标题、正文、醒来心情、醒后碎碎念、修改、删除和近期记录回看。
- 梦境会进入 IndexedDB、本地镜像、版本快照和 JSON 完整备份。
- 不依赖外部图片或网络字体，离线 PWA 仍可正常显示。

部署时请将压缩包中的全部文件覆盖到 GitHub 仓库根目录。覆盖前建议先在旧版本中点击一次“立即备份”。


## v1.9.23 更新
- 上一版困难题库按原题号迁移为新的简单题库。
- 新中等改为4箱、更多墙体与至少32次反向有效推动。
- 新困难改为5箱、狭窄通道与至少52次反向有效推动。
- 中等和困难要求每个箱子都参与解题，减少看似箱子多但实际只需移动一两个箱子的关卡。


## v1.9.24 更新
- 推箱子中等升级为5箱、更长路径；困难升级为6箱、狭窄通道与更高调位要求。
- 月预算区域新增现有存款和按月份保存的当月存款。
- 底部导航固定为：首页、日历、记账、家务、探店、愿望、脑力、居民、备份。


## v1.9.25 更新
- 全站改为像素田园冒险风格：木牌标题、草地与山景、硬边框、像素阴影和复古纸张面板。
- 首页、日历、记账、家务、探店、愿望、脑力、备份以及弹窗统一换肤。
- 四个脑力游戏的棋盘、按钮和状态栏同步改为像素游戏界面。
- 居民模块只调整面板与按钮外观，所有居民 Emoji、宠物 Emoji、名称和养成数据保持不变。
- 不依赖外部图片或网络字体，离线 PWA 可正常显示。


## v1.9.26 更新
- 全站继续使用原创的温暖农场像素风界面，不调用游戏原始素材，离线也能显示。
- 居民模块中的动物 Emoji、名称、关系和养成数据全部保持原样。
- 在“家务”后新增“记梦”导航与记梦笔记本。
- 页面顶部可选日期，也可切换前一天、后一天或回到今天。
- 点击大型像素笔记本后，可记录梦的标题、正文、醒来心情和醒后碎碎念。
- 保存后的梦境会显示在书封摘要与近期记录中，可按日期回看、修改或删除。
- 梦境数据会进入 IndexedDB、本地镜像、版本快照和 JSON 完整备份。
