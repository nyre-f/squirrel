# 小松鼠生活管家 v1.9.47

- 删除足迹地图入口，新增“🌿 人生轨迹”。
- 人生轨迹是可纵向上下滑动的时间轴，可以记录某一天发生的事，也可以只记录到某年某月。
- 支持直接输入年份和月份并跳转到当时；没有记录的月份也会显示为空月份位置，方便继续补写。
- 每条记录自动保留创建/修改信息，可编辑、删除，并按年月整理在同一条纵向时间轴上。
- 按手机手势上下拖动即可浏览过去，时间轴区域独立滚动。
- 按本次调整移除人生轨迹模块最外层的大框与底部说明注释，让时间轴直接融入页面；原有像素农场配色与按钮风格不变。
- 旧版地图数据不会主动清空，以免备份中的历史数据被意外破坏，但地图功能和入口已从界面移除。
- IndexedDB 继续使用向上兼容打开逻辑，不会因为本地数据库版本较高而降级失败。
