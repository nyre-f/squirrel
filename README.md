# 小松鼠生活管家 v1.9.54

## v1.9.54 · 植物日历
- 新增“🪴 植物日历”模块，首页和“更多”均可进入。
- 每盆植物可设置名称、图标、独立浇水周期与长期养护便签。
- “今天浇水”自动记录当天日期与实际时刻；“补记浇水”可填写过去的日期、时间和备注。
- 每盆植物显示上次实际浇水、依据周期计算的下一次建议检查日期，以及是否已到建议检查时间。
- 新增月历视图，水滴只表示真实发生过的浇水记录；可按单盆植物筛选。
- 新增最近浇水历史，可删除误记记录。
- 植物、浇水历史与养护便签进入原有 JSON 完整备份和恢复流程。

## 同时保留此前升级
