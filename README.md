# 小松鼠生活管家 v1.9.52

- 在“家务”页面新增“🧴 日用品更换”区域。
- 内置四项：牙刷、毛巾、擦桌抹布、擦手抹布。
- 默认更换周期：牙刷 90 天、毛巾 90 天、擦桌抹布 30 天、擦手抹布 30 天；每项均可自行修改。
- 每项显示上次更换、下次更换、已使用天数和剩余天数，并用状态标签提示“待设置 / 还有几天 / 今天该换 / 已到期”。
- 点击“今天换新”即可把当天记为新的更换日期并重新开始计时；第一次可用“今天开始”。
- “设置”里可以修改更换周期和上次更换日期。
- 旧版数据升级时会自动补入四项日用品，不覆盖原有家务、人生轨迹、账本等数据。
- v1.9.50 的人生轨迹年/月折叠及旧日历迁移逻辑继续保留。
- 数据结构版本升级为 47。
