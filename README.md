# 小松鼠生活管家 v1.9.21

本版更新：

- 空当接龙恢复标准规则：牌列红黑交替、数字递减，收集区同花色从 A 到 K。
- 连续牌组只能在临时空间足够时整组移动；空列目标不会被重复计入可用空间。
- 选中牌组后会显示当前可移动上限，失败时说明是接牌规则错误还是容量不足。
- 保留自动收牌、死局提示、完整牌面、暂停继续与撤销功能。
- 养成、心情日历、背景商店和完整家具等原有数据与功能全部保留。

部署时将压缩包中的全部文件覆盖到 GitHub 仓库根目录。上传前建议先执行一次“立即备份”。


## v1.9.16 自动收牌修复
- 自动收牌会在开局、重置、重新打开牌局和正常移动后持续扫描。
- 修正过于保守的安全牌判断。
- 增加“立即收牌”按钮，可手动扫描所有当前安全牌。


## v1.9.17 日历心情记录本
- 日历详情新增可无限追加的碎碎念与思考记录，并保存记录时间和所属时段。
- 上午、下午、晚上分别支持自选颜色。
- 有心情记录的日期格由上到下用三段颜色完整铺满。
- 心情颜色与碎碎念随 JSON 备份和本地快照保存。


## v1.9.18 更新
- 修复商店背景已选择但被原场景底色遮挡的问题。
- 当前场景画面固定为免费默认背景，背景商店新增明确的“默认背景”卡片。
- 购买背景后立即应用；已购买背景可反复替换。
- 首次升级会恢复默认背景，但保留所有已经购买的背景。
- 替换背景时保留道路、家具、池塘、房屋和 Emoji 摆设等前景元素。


## v1.9.19 更新
- 新增 22 件完整 CSS 家具，包括桌子、书柜、衣柜、沙发、床、灯、地毯、壁炉、厨房柜台和梳妆台。
- 家具为独立矢量组件，不使用两本书、多个 Emoji 或零散符号拼成大型家具。
- 家具拥有独立商店分区，购买一次后可在各场景反复摆放、复制、移动、缩放和调整图层。
- 树屋默认布局中的 Emoji 沙发、椅子等替换为完整家具；用户后来购买并摆放的自定义物品继续保留。


## v1.9.21 更新
- 空当接龙恢复标准规则：牌列按红黑交替、数字递减连接。
- 自由格每格只能放一张牌，收集区按同花色 A 到 K 递增。
- 空列可以接收任意单牌或合法连续牌组，但整组长度受空自由格和空列数量限制。
- 超级移动容量：接到非空牌列为 `(空自由格+1)×2^空列数`；移入空列时目标空列不计作临时空间。
- 选中牌组后显示当前可移动上限，移动失败会说明具体原因。


## v1.9.21 更新
- 空当接龙加入简单、中等、困难三套编号题库。
- 支持输入第1—999999题、上一题、下一题、随机一题及最近题目快捷入口。
- 同一难度与题号会稳定生成同一副牌。
- 简单和中等仍为52张完整发牌、空白收集区，不预收低点数牌；通过筛选完整随机开局控制难度。
- 困难保持原先未经筛选的完全随机难度。
