# 小松鼠生活管家 v1.9.56

## 自动更新修复
- 启动时主动注册并检查 Service Worker 更新，注册使用 `updateViaCache: none`，降低 Edge/PWA 长时间停留旧版的概率。
- 发现新版本后，页面底部会显示“立即更新 / 稍后”提示；点“立即更新”后切换到新版并自动重载。
- 备份页新增“应用更新”区域，可手动“检查新版”或“强制刷新应用”。
- “强制刷新应用”只清除以 `squirrel-life-` 开头的 Cache Storage，不删除 IndexedDB、localStorage、账本、人生轨迹、植物、家务等本地数据。
- 首页增加明显的当前版本 `v1.9.56` 标记。
- Service Worker 的页面导航采用网络优先并禁用 HTTP 缓存，离线时再回退到缓存页面。
- 保留 v1.9.55 家务暂停和此前全部功能；数据结构版本仍为 50，无需迁移生活数据。


- 家务项目新增“暂停 / 恢复”。
- 暂停后该项目不再参与“优先打扫 / 快到期”提醒，也不会计入首页待处理家务。
- 暂停时会冻结当前周期进度；恢复时自动扣除暂停的天数，继续使用暂停前剩余时间。
- “刚刚完成”仍用于提前完成家务：会把当天设为新的完成日期，并自动解除暂停、从当天重新计时。
- 家务筛选新增“已暂停”。
- 为避免按钮继续变多，家务卡片只直接显示“刚刚完成 / 暂停（恢复）”，编辑和删除收进“•••”菜单。
- 旧版家务数据会自动补充暂停字段，不影响原记录。
- 数据结构版本升级为 50。

# 小松鼠生活管家 v1.9.54

## v1.9.54 · 植物日历
- 新增“🪴 植物日历”模块，首页和“更多”均可进入。
- 每盆植物可设置名称、图标、独立浇水周期与长期养护便签。
- “今天浇水”自动记录当天日期与实际时刻；“补记浇水”可填写过去的日期、时间和备注。
- 每盆植物显示上次实际浇水、依据周期计算的下一次建议检查日期，以及是否已到建议检查时间。
- 新增月历视图，水滴只表示真实发生过的浇水记录；可按单盆植物筛选。
- 新增最近浇水历史，可删除误记记录。
- 植物、浇水历史与养护便签进入原有 JSON 完整备份和恢复流程。

## 同时保留此前升级
- 人生轨迹：旧日历记录自动迁入；日历模块移除；全屏时间轴；年/月折叠；日/月/年三种记录精度。
- 家务：牙刷、毛巾、擦桌抹布、擦手抹布更换周期记录。
- 探店：移除底部规则说明，记录从新到旧连续向下浏览并按月分组；次要操作收进“•••”。
- UI：常规按钮降噪，保留主要操作层级。
- 预算：每个月可独立新增、改名、改金额或删除预算项；旧月份互不影响。
- 数据结构版本：49。
