# 小松鼠生活管家 v1.9.26

在 v1.9.25 的功能基础上，整体界面改为更柔和、偏木质、适合长时间阅读的风格。

本次视觉调整包括：

- 保留原有布局与全部功能，仅调整 UI 视觉。
- 从高对比像素农场风，调整为暖米色、木色与低饱和森林绿。
- 全站字体改为更易读的系统无衬线字体，降低阅读疲劳。
- 卡片、输入框、按钮、底部导航、记梦本和日历统一为更柔和的圆角与浅阴影。
- 提高正文行距与文本对比度，让记账、记梦和长段文字更容易阅读。
- 保留树屋、脑力、记梦、居民、备份等全部功能不变。

部署时，将压缩包中的全部文件覆盖到 GitHub 仓库根目录。上传前建议先在旧版中执行一次“立即备份”。
