# 小松鼠生活管家 v1.9.11

本版升级树屋居民养成循环：

- 食物扩充至 16 种，按份使用生活积分购买；旧存档会获得胡萝卜、苹果和面包 starter 食物。
- 玩具扩充至 14 种，每件只需解锁一次，之后可以反复使用。
- 每日第一次新增当天账目可获得 5 积分。
- 每日日历打卡、保存当天记录或完成当天待办可获得 5 积分，同一天只奖励一次。
- 宝宝饥饿下降速度提高，更适合一天多次喂食；健康惩罚相应放缓。
- 宝宝清醒时会在当前场景附近自己散步，不改变布置模式中保存的基准位置。
- 原有 Emoji 商店、场景布置、挂机居民、四种脑力游戏和旧存档继续保留。

部署时，将压缩包中的全部文件覆盖到 GitHub 仓库根目录。上传前建议先在旧版中执行一次“立即备份”。
