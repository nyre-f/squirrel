## 升级方式

1. 先在旧版点击“立即备份”。
2. 将本文件夹中的全部文件上传并覆盖 GitHub 仓库根目录。
3. 手机端若仍显示旧界面，请完全关闭后重新打开；必要时清除该站点缓存再安装。
4. 不要把私人 JSON 备份上传到公开仓库。
