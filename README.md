# 小松鼠生活管家 v1.9.46

## 本次更新：小松鼠人生轨迹

- 删除“足迹地图”界面与离线地图资源，改为独立的“🕰️ 小松鼠人生轨迹”。
- 人生轨迹像一本按月份翻阅的日记：一天可以记录多件事情，每条可填写日期、可选时间和正文。
- 支持编辑、删除和以后补记旧日期，不限制只能记录今天。
- 顶部提供可直接拖动的时间轴；时间轴会根据现有记录自动向更早或更晚的月份扩展。
- 支持直接输入“年月”跳转，例如 2025-08；也有上月、下月、回到现在快捷按钮。
- 每个月下方自动显示“一年前的这个月”，方便回看去年同期自己大概在做什么、想什么。
- 月份页面按日期分组，同一天的多条小事件会放在一起。
- 旧版地图如果已有手动打卡记录，会在首次升级时转成人生轨迹中的“📍 去过……”记录，之后地图模块从数据结构中移除。
- 人生轨迹会随完整 JSON 备份一起导出。

## 数据安全

- 数据结构版本升级到 43。
- 继续沿用 v1.9.45 的 IndexedDB 向上兼容打开方式，不会因为数据库版本比代码高而启动失败。
- 不会清空现有账本、日历、梦境、读后感、阅读器、游戏或居民数据。
