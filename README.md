# 小松鼠生活管家 v1.9.46

- 删除足迹地图模块，改为独立的“🐿️ 小松鼠人生轨迹”。旧地图界面与离线地图数据不再随应用加载。
- 人生轨迹使用纵向时间轴，手机可直接上下滑动，电脑可按住时间轴空白处拖动浏览。
- 节点完全由自己添加，并按时间从近到远排列；支持三种时间精度：年月日、年月、只有年份。
- 每个节点可填写小标题和正文，适合记录“这天做了什么”“那个月大概在忙什么”“那几年大概是什么状态”。
- 顶部可输入年月并定位到最接近的节点，也可一键查看“一年前”和返回最近节点。
- 节点支持编辑和删除，所有内容进入生活管家的本地存档、版本快照和 JSON 完整备份。
- 升级时会移除旧 travelMap 模块数据结构，不影响日历、账本、读后感、阅读器等其他数据。
- 延续 v1.9.45 的 IndexedDB 向上兼容逻辑，不会再因数据库版本倒退而启动失败。
