# 小松鼠生活管家 v1.9.29

## 本版更新

- 全应用换成复古像素农场风：木牌标题、羊皮纸面板、像素描边、草地背景、木质底部导航和像素按钮。
- 树屋居民中的动物 Emoji 全部保持原样。
- 家务后新增“记梦”功能，底部顺序为：首页、日历、记账、家务、记梦、探店、愿望、脑力、居民、备份。
- 记梦笔记本支持选择日期、前一天、后一天和回到今天。
- 每天可保存梦境标题、详细内容与关键词，并可从近期梦境纸页直接翻回对应日期。
- 梦境数据会进入 IndexedDB、本地镜像、版本快照和 JSON 完整备份。
- 原有记账、存款、心情日历、家务、探店、愿望、脑力游戏、宝宝养成、居民、背景与家具系统全部保留。

## 部署

将压缩包内全部文件覆盖到 GitHub 仓库根目录。覆盖前建议先在旧版本中点击一次“立即备份”。


## v1.9.29 更新
- 在像素农场结构上改为柔和、适合长时间阅读的低饱和配色。
- 新增小松鼠阅读器，支持 TXT、Markdown、HTML、PDF 与 EPUB；IndexedDB 中只缓存当前一本书。
- 阅读器支持章节切换、字号、行距、纸页/夜读主题和章节进度。
- 空当接龙在手机端缩小牌面与间距，八列完整贴合屏幕。
- 推箱子根据地图列数动态计算格子大小，避免横向拖动。


## v1.9.29 更新
- 底部导航改为首页、日历、记账、阅读、更多的一行紧凑栏，其余功能收入像素抽屉。
- IndexedDB 升级到新版并自动补建 readerBooks 仓库，修复旧设备上传 EPUB 时提示 object store 不存在。
- 阅读器新增小松鼠读书笔记本，可按当前书籍保存章节、进度和阅读想法。
- 读书笔记进入 JSON 备份；电子书原文件仍只在本机缓存一本。


## v1.9.29 更新
- 过滤 EPUB 正文中的搜索、缩放、导航按钮图标与小型无说明方形控件图。
- 修复带锚点目录造成的章节标题错位，并用正文真实标题回写章节列表。
- 新增小松鼠书架，电子书替换或清除后仍保存书名、进度、读完日期和笔记。
- 支持手动记录纸质书，并为电子书与纸质书追加长期书架笔记。
- 当前仍只缓存一本电子书原文件，书架记录进入 JSON 备份。


## v1.9.29 更新
- 修复 EPUB 原书小图标被阅读器放大的问题。
- 搜索、标注、批注、脚注等界面图标会优先过滤。
- 重复出现且无说明的方形标注图片会自动隐藏。
- 其余小型行内图片压缩为约四分之一个字高，并尽量并入相邻文字，不独占一行。
- 普通插图保留原始长宽比，并在页面宽度内按原始尺寸展示。
