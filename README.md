# 小松鼠生活管家 v1.9.25｜记梦笔记本与柔和森林手账

本版更新：

- 推箱子新增简单、中等、困难三套编号题库。
- 支持输入第 1—999999 题，也可使用上一题、下一题、随机一题和最近题目快捷入口。
- 同一难度与题号会稳定生成同一关卡。
- 关卡从完成状态反向生成，保证存在解法。
- 简单题为 1 个箱子和短路线；中等题为 2 个箱子、转弯与墙体；困难题为 3 个箱子和更长推动路线。
- 通关记录会保存难度、题号、步数、推动次数与积分奖励，最近题目会标记是否完成。
- 原有暂停、继续、撤销、重置、方向键和 WASD 操作全部保留。
- 空当接龙三难度题库、心情日历、宝宝养成、背景商店和完整家具等功能继续保留。

部署时将压缩包中的全部文件覆盖到 GitHub 仓库根目录。上传前建议先执行一次“立即备份”。


## v1.9.23 更新
- 上一版困难题库按原题号迁移为新的简单题库。
- 新中等改为4箱、更多墙体与至少32次反向有效推动。
- 新困难改为5箱、狭窄通道与至少52次反向有效推动。
- 中等和困难要求每个箱子都参与解题，减少看似箱子多但实际只需移动一两个箱子的关卡。


## v1.9.24 更新
- 推箱子中等升级为5箱、更长路径；困难升级为6箱、狭窄通道与更高调位要求。
- 月预算区域新增现有存款和按月份保存的当月存款。
- 底部导航固定为：首页、日历、记账、家务、探店、愿望、脑力、居民、备份。


## v1.9.25 更新
- 在家务后新增“记梦”模块：顶部可选择日期并切换前一天、后一天。
- 点击大笔记本打开当天梦境编辑页，可保存标题和完整梦境内容。
- 新增近期梦境入口，梦境数据进入本地存档、快照和 JSON 备份。
- 全站更换为低饱和暖米色与森林绿色手账风，降低阴影和视觉噪声，增加正文行距。
- 底部十项导航在手机端采用两行五列，保持按钮可读性。
