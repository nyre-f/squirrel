# 小松鼠生活管家 v1.9.56

## 自动更新与手机适配
- Service Worker 注册改为 `updateViaCache: none`，打开页面后主动检查新版，并在页面重新可见、网络恢复以及每 30 分钟时再次检查。
- 发现新版时显示“发现小松鼠管家新版”提示，可点“立即更新”。
- “备份”页面新增“应用更新”区域，可手动“检查新版”或“清缓存并刷新”。
- “清缓存并刷新”只删除以 `squirrel-life-` 开头的 Cache Storage 离线文件，不主动删除 IndexedDB / localStorage 中的生活数据。
- 导航请求改为网络优先并使用 `cache: no-store`，减少 GitHub Pages / Edge 长时间停留在旧 HTML 的情况。
- 手机端增加全局宽度兜底，修复部分面板、弹窗、输入框、工具栏略微超出屏幕的问题。
- 420px 以下进一步压缩页面左右留白，工具栏和顶部操作区自动重排，避免横向溢出。
- 继承 v1.9.55 家务暂停、v1.9.54 植物日历以及此前全部数据与功能。
