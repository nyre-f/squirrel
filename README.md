# 小松鼠生活管家 v1.9.4

这是一版继续根据你的想法细化后的部署包，重点更新：

- 树屋场景修正：把不合理“飘在墙上/天上”的书、闹钟等物件挪到地面附近。
- 去掉提示弹幕：“把道具拖给宝宝，或再点一次宝宝”。
- 夜景树屋优化：窗外去掉树，保留更清晰的田字形大窗与夜景。
- 四个场景统一加密度：森林、树屋、草地、村庄都增加了更多摆设与装饰元素。
- 新增小游戏积分系统：完成数独、空当接龙、扫雷可获得积分。
- 新增场景布置模式：可购买 emoji 摆设并布置到当前场景。
- 新增自由编辑：在布置模式中可拖动摆设位置，调节前后层级、大小，还能复制或删除摆设。
- 修复居民“挂机”按钮可直接使用。

## 本版说明

打开“树屋/村庄”页面后，在社交分类里点“🪄 布置”，即可进入布置模式。

在布置模式中：

- 点击场景里的 emoji 可选中它。
- 拖动场景里的 emoji 可调整位置。
- 面板里可以调前后层级、放大缩小、复制、删除。
- 用小游戏赚到的积分可以在商店购买更多摆设。

## 部署方式

直接上传全部文件到 GitHub Pages / 静态网站空间即可。

如果浏览器缓存了旧版本，刷新或清缓存后再打开即可。
