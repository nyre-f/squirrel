# 小松鼠生活管家 v1.9.53

## v1.9.53 · 自由月预算
- 月度预算改为按月份独立保存：每个月都可以拥有完全不同的预算名称与金额。
- “调整月预算”中可直接新增、重命名、删除预算项，并自由填写预算额。
- 新增“沿用上月”，可快速复制上个月的预算结构后再修改。
- 预算名称改名时，会同步更新该月已有支出的预算池名称，避免统计断开。
- 删除预算项只删除预算配置，不会删除已有账目；历史账目仍可在筛选中找到。
- 旧版五个固定预算池继续作为兼容模板，旧数据不会丢失。
- 数据结构版本升级为 48。
