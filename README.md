# 小松鼠生活管家 v1.9.44

本版重点：三级下钻与离线足迹地图。

- 地图按“全国 → 省 → 市 → 区县”直接下钻；点击地区时同步点亮该级足迹。
- 省、市、区县都能单独保存旅行日期、景点与感想。
- 地图支持拖动、滚轮/双指缩放、双击以及 +/-/适应按钮。
- 新增“准备全部边界”：首次准备会下载行政边界并放入浏览器 Cache Storage；准备完成后行政地图可断网读取。
- 新增本地道路/街道瓦片导入：支持标准 XYZ 文件夹结构 `z/x/y.png|jpg|webp`，导入后瓦片保存在 IndexedDB，之后不请求在线路网。
- 原有省、市足迹和旅行记录继续保留，并新增区县级记录。

部署：将本压缩包全部文件覆盖到 GitHub Pages 仓库根目录。更新后建议完全关闭旧页面再重新打开，以升级 IndexedDB 与 Service Worker。
