# 小松鼠生活管家 v1.9.4

本次新增“🐣 树屋居民”养成游戏：

- 🥚 可从松鼠、兔子、猫、狗、仓鼠、狐狸和小熊中选择居民并起名。
- 🍎 每天需要喂食、陪玩和清洁，饱腹、心情、清洁及健康会随真实时间变化。
- 🌙 按中国时间生活：22:00—次日7:00自动睡觉，睡觉时只能轻轻盖被子。
- 💀 饥饿、心情和清洁长期过低会损害健康；连续多日无人照顾可能死亡，并进入纪念册。
- 🏘️ 内置7位村庄居民，可每日聊天、积累友情，并触发雨天、野餐、音乐会、失物等随机事件。
- 💍 小居民成年且健康良好，与某位居民友情达到70后可以结婚。
- 🐣 婚后可迎接小宝宝，宝宝会随真实天数成长，家庭成员会保存在树屋中。
- 📖 所有照顾、事件、婚礼、宝宝和离别都会写入树屋日记，并纳入完整 JSON 备份。
- 😀 界面人物、食物、游戏、居民和事件图标均直接使用 Emoji。

原有的叠层 Emoji Logo、餐厅与外卖、日历、记账、愿望冷静箱、家务、数独、空当接龙、扫雷及备份功能均保留。

## 升级方式

1. 先在旧版点击“立即备份”。
2. 将本文件夹中的全部文件上传并覆盖 GitHub 仓库根目录。
3. 等待 GitHub Pages 部署完成后，完全关闭手机上的网页或 PWA，再重新打开。
4. 若仍显示旧页面，可在浏览器中打开网页并刷新；不要在未备份前清除站点数据。
5. 不要把私人 JSON 备份上传到公开仓库。
