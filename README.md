# 小松鼠生活管家 v1.9.27

## 小松鼠阅读器
- 支持上传 EPUB、TXT、Markdown、HTML 和 PDF。
- 电子书文件保存在浏览器 IndexedDB 中，只使用一个缓存槽位；上传新书会自动覆盖旧书。
- 自动保存文字书阅读进度、PDF 当前页、字号、行距、页面宽度与主题。
- 日常 JSON 备份只保存书名、进度与显示设置，不包含整本电子书。

## UI 与手机适配
- 修复底部导航文字重叠，十一项导航在手机上自动排成两行。
- 重新平衡浅色背景与深棕色，卡片层次更清楚、木色更柔和。
- 空当接龙整体缩小，在常见手机屏幕上完整容纳八列。
- 推箱子会按地图列数自动计算格子尺寸，尽量无需左右拖动。

部署时请将压缩包中的全部文件覆盖到仓库根目录。更新前建议先在旧版点击一次“立即备份”。
