# 小松鼠生活管家 v1.9.15

本版更新：

- 宝宝的饱腹、心情、清洁和健康消耗加快，更需要每天多次喂食、玩耍和照顾。
- Emoji 商店扩充桌子、收纳家具、水池、山峦、湖面、花田、瀑布等室内与风景摆设。
- 森林、树屋、草地和社区各新增 4 套可用积分购买的背景主题；购买一次后可反复替换。
- 继续支持上传自己的背景图，并可随时恢复默认背景。
- 宝宝自由散步时会根据左右移动方向自动翻转 Emoji，避免出现倒着走的感觉。

部署时将压缩包中的全部文件覆盖到 GitHub 仓库根目录。上传前建议先执行一次“立即备份”。


## v1.9.15 空当接龙修复
- 空列现在可以直接接收任意长度、红黑交替且数字递减的完整连续牌组。
- 非空牌列仍按标准临时空位容量限制移动长度。


## v1.9.15 更新
- 合法的红黑交替、数字递减牌组可以直接整组接到匹配的目标牌列。
- 牌组连接不再受自由格和空列数量限制。
- 接牌失败时会提示目标牌所需的点数与颜色。
