# 小松鼠生活管家 v1.9.59

## v1.9.59 · 旅行到区 / 独立预算包

### 松鼠足迹
- 旅行页第一屏最上方固定为交互地图。
- 地图层级升级为：中国 → 省级地区 → 地级市 → 区 / 县。
- 点击到区县后地图不会消失，仍保留当前城市的区县地图，并高亮当前区县。
- 面包屑路径同步细化到区县；直辖市自动去除重复的“北京 > 北京”式路径。
- 新增/编辑旅行记录时，省、市、区/县都进入记录路径；新记录要求填写到区/县一级。
- 旅行记录新增 `districtCode` / `districtName`，旧版只有城市级的旅行记录仍会保留，可后续编辑补充区县。
- 地图访问状态继续由旅行记录自动计算，不单独硬编码。
- 搜索支持省、市、区县、标签、旅行文字和年份；在城市行政索引可用时，可直接定位尚未留下旅行记录的城市/区县。
- 地图、时间轴、随机回忆、照片、旅行 JSON 单独导入/导出等功能继续保留。
- 地图支持触屏拖动、双指缩放、滚轮/按钮缩放；宽度受手机屏幕约束。

### 预算包
- 在账本中新增长期/一次性“预算包”，例如“宁波旅行 5000”“Alfred 周边 2000”。
- 预算包与月预算完全独立保存、独立显示余额。
- 支出账目可以选择关联一个预算包。
- 关联预算包的支出仍计入真实“本月支出”，但**不会扣减月预算余额**；只扣减对应预算包余额。
- 月预算仍然按月份独立设置名称和额度；预算包不计入月预算总额。
- 删除预算包只解除账目关联，不删除原账目。

### 继续保留
- 家务暂停 / 恢复、日用品更换、固定展开家务卡片。
- 植物日历、实际浇水记录与养护便签。
- 新事件 / 扩窝计划、经验库和轻量回顾。
- 人生轨迹（日 / 月 / 年记录与年/月折叠；旧日历内容迁入轨迹）。
- 探店连续历史、愿望箱、阅读器、梦境、读后感、树屋居民和脑力房。
- 自动备份、快照、PWA 自动更新与手机防溢出。
