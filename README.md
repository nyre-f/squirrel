# 小松鼠生活管家 v1.9.56

## 家务卡片重新布局
- 家务卡片取消“•••”展开式菜单，所有操作按钮直接显示在卡片上。
- 卡片顶部统一为“家务名称 + 状态”，中间显示上次完成、已经过去、建议周期。
- 底部固定四个操作：刚刚完成、暂停/恢复、编辑、删除。
- 宽屏四个按钮整齐一排；窄屏手机自动变为 2×2，不横向溢出。
- 暂停逻辑、自动更新、手机防溢出、植物日历、每月自定义预算等既有功能继续保留。


## 家务暂停
- 每项家务增加“暂停提醒 / 恢复倒计时”。
- 暂停期间不计算逾期，也不会排到“优先打扫”前面。
- 恢复时会把暂停经过的天数顺延到上次完成日期，保留暂停前剩余的周期，不会一恢复就突然逾期。
- 暂停期间如果提前换了床单、被套等，直接点“刚刚完成”：会自动解除暂停，并从当天重新开始计算周期。
- 家务筛选新增“已暂停”。
- 次要操作收进“•••”，家务页按钮更简洁。

## 自动更新
- PWA 注册改为 `updateViaCache: none`，打开页面、重新获得焦点、从后台回来以及每 5 分钟都会主动检查新版。
- Service Worker 对页面与静态文件优先向网络检查最新版本；新版接管后页面自动刷新一次。
- 页面跨过零点后会自动刷新家务、日用品和植物等日期相关状态，不必手动刷新才能看到“今天”的新倒计时。

## 手机画面适配
- 全局限制页面、卡片、表单、弹窗、输入框最大宽度，阻止横向溢出。
- 700px 以下统一压缩页面边距；420px 以下记录卡片改为单列。
- 修正植物日历工具栏、日历格、底部导航和弹窗在窄屏手机上的宽度。

数据结构版本：50。
