# 小松鼠生活管家 v1.9.46

- 足迹地图改为完全本地的轻量离线地图，不再请求在线 GeoJSON/地图服务。
- 地图按“中国 → 省 → 市 → 区县 → 道路”逐级下钻；点击地图只负责选择/进入，绝不会自动打卡。
- 每一级都可点击“📍 打卡这里”手动写入足迹；道路层先点击任意位置放临时定位针，再点击“📍 打卡这个点”确认。
- 打卡记录自动保存地点层级、具体时间；道路点同时保存本地坐标，并在地图上留下小脚印。
- 道路层支持放大、缩小、复位和拖动浏览，最高 16×。
- 当前轻量离线包重点内置：全国省级位置、江苏 13 个地级市、北京 16 个区、徐州 10 个区县/县级市，以及北京中心城区、徐州中心城区的道路骨架和少量标志性地点（含天坛公园、云龙湖、苏宁广场等）。
- 其他省份先内置省会/少量主要城市，可在对应层级手动打卡；未内置的区县/道路不会联网补载。
- 旧版足迹点亮数据会一次性迁移为“旧足迹”打卡记录，不丢历史。

- 修复 IndexedDB 版本倒退导致的启动失败：不再固定请求旧版本，而是先读取手机现有数据库版本，仅在需要时向上升级。
- 当前最低目标数据库版本为 5；如果本地数据库已经高于 5，会直接沿用更高版本，避免再次出现 VersionError。
- 修复只升级数据库容器版本，不清空、不重建现有 state、snapshots、readerBooks 数据。


## v1.9.46 足迹地图交互升级
- 点击省份直接进入市级地图，点击城市直接进入区县地图，点击区县进入道路层；单纯打开地图不会自动打卡。
- 中国、省、市、区县、道路每一层都支持拖动、鼠标滚轮和手机双指缩放，最高 16×。
- 每一级都保留“打卡当前层级”，打卡时间由应用自动记录。
- 新增“手动选点”模式：开启后再轻点地图任意位置放置临时定位针，确认后才保存打卡；可在保存时自定义地点名称。
- 手动选点保存经纬度、层级路径和时间；已保存点会在对应地图层显示足迹。
- 北京中心城区与徐州中心城区继续提供完全离线的轻量道路/地标底图；其他未内置道路数据的区县不会联网补图，但仍可缩放、选点和层级打卡。
