# 小松鼠生活管家 v1.9.48

- “🌿 人生轨迹”升级为全屏纵向时间轴，进入后隐藏普通页面框架和底部导航。
- 时间轴从“现在”开始，按时间从近到远向下延伸；手机直接上下滑动浏览。
- 电脑端可在时间轴空白处按住鼠标上下拖动，像拖动画布一样翻看人生。
- 记录节点支持三种时间精度：具体某一天、只记某月、只记某年。
- 原顶部按钮与跳转栏全部收进右侧半透明毛玻璃气泡菜单，包含“记录节点、跳到时间、回到现在、返回管家”。
- 跳转支持按年份或年月定位；目标时段没有节点时，会自动靠近到最近的已有记录。
- 删除原人生轨迹底部说明文字与占位式注释，只保留时间轴本身。
- 旧版人生轨迹记录会自动兼容，不会清空；备份、IndexedDB 与 localStorage 镜像机制保持不变。
