# 小松鼠生活管家 v1.9.53

## v1.9.53 · 每月自定义预算
- 预算改为按月份独立保存：每个月都可以拥有完全不同的预算名称和额度。
- “编辑本月预算”中可以直接修改预算名称、修改金额、新增预算项或删除预算项。
- 修改某个月的预算名称时，会同步更新该月已经使用旧预算池名称的支出记录，避免账目断开。
- 删除预算项不会删除历史账单；如果历史支出仍使用已删除的预算池，会以“未设预算”的历史卡片继续显示。
- 新月份尚未单独设置预算时，会优先沿用最近一个已设置月份的预算作为编辑起点；保存后即成为该月独立配置。
- 记账时预算池会按照账单日期自动切换到对应月份；切换账本月份时，筛选器也会跟着更新。
- 旧版固定预算会在升级时复制到已有账目月份，旧数据不会丢失。
- 数据结构版本升级为 48。


- 在“家务”页面新增“🧴 日用品更换”区域。
- 内置四项：牙刷、毛巾、擦桌抹布、擦手抹布。
- 默认更换周期：牙刷 90 天、毛巾 90 天、擦桌抹布 30 天、擦手抹布 30 天；每项均可自行修改。
- 每项显示上次更换、下次更换、已使用天数和剩余天数，并用状态标签提示“待设置 / 还有几天 / 今天该换 / 已到期”。
- 点击“今天换新”即可把当天记为新的更换日期并重新开始计时；第一次可用“今天开始”。
- “设置”里可以修改更换周期和上次更换日期。
- 旧版数据升级时会自动补入四项日用品，不覆盖原有家务、人生轨迹、账本等数据。
- v1.9.50 的人生轨迹年/月折叠及旧日历迁移逻辑继续保留。
- 数据结构版本升级为 47。
