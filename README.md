# 小松鼠生活管家 v1.9.46

- 删除足迹地图模块及地图界面/地图数据，更多菜单中的“地图”替换为“🐾 轨迹”。
- 新增“🐿️ 小松鼠人生轨迹”：用纵向时间轴记录某一天做了什么。
- 时间轴支持手机上下滑动/拖动浏览，最新月份在上方，向下可以回到更早以前。
- 支持直接输入“年月”跳转，也可以一键回到当前月份。
- 同一天可以保存多条记录，每条自动保留记录时间；支持编辑和删除。
- 时间轴默认展示最近 24 个月，即使某个月没有记录也保留月份刻度；录入更早日期或跳到更早年月后会自动扩展。
- 旧足迹地图如果曾经保存过打卡，会一次性转换为对应日期的“去了……”人生轨迹记录，然后移除旧地图模块，尽量不丢历史。
- 数据结构版本升级到 43；IndexedDB 继续使用向上兼容打开方式，不会因数据库版本回退导致启动失败。
