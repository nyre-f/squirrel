# 小松鼠生活管家 v1.9.6

本版升级树屋居民布置系统：

- Emoji 最大可放大到 20 倍，并提供连续缩放滑杆。
- 布置工具栏移动到游戏画面外，不再遮挡底部物件。
- 扩充 Emoji 商店，增加动物、家具、食物、自然、户外和幻想摆件。
- 四个场景均可从手机选择自定义背景图片，可切换铺满或完整显示。
- Nyre/当前领养动物可以在布置模式中拖动位置、调整大小与上下图层。
- 原有积分、已购买 Emoji、场景布局和小游戏奖励继续保留。

部署时，将压缩包中的全部文件覆盖到 GitHub 仓库根目录。上传前建议先在旧版中执行一次“立即备份”。


## v1.9.6 更新
- 挂机居民以动物模型留在场景中，可主动结束挂机。
- 聊天结束不会自动进入挂机。
- 底部导航将居民与脑力移至最后。
- 脑力房新增推箱子，并接入场景积分奖励。
