# 小松鼠生活管家 v1.9.27

## 本次更新

- 新增“小松鼠阅读器”，支持 TXT、Markdown、HTML、EPUB 和 PDF。
- 阅读器使用独立 IndexedDB 缓存，始终只保存当前一本书；上传新书会替换旧书。
- TXT、Markdown、HTML、EPUB 支持舒适排版、字号调整和滚动进度保存。
- PDF 使用浏览器内置阅读器，并提供页码跳转。
- 修复底部导航选中模块后文字挤压、重叠的问题。
- 重新平衡界面颜色，提高浅色区域辨识度，同时减轻过深棕色。
- 空当接龙手机端缩小间距和牌面，八列完整适配屏幕。
- 推箱子根据地图列数和手机宽度自动计算格子尺寸，尽量不再横向拖动。
- 保留 v1.9.26 的全部数据与功能。

电子书原文件不会写入 JSON 备份；清除浏览器数据前请保留原书文件。部署时将压缩包中的全部文件覆盖到仓库根目录。
