# 小松鼠生活管家 v1.1 · 数独版

本次新增“脑力”模块和离线数独，同时保持原有的数据仓名称与存储键不变。

## 升级前

1. 在当前网站里点“立即备份”。
2. 确认手机已下载 JSON 备份。
3. 不要改 GitHub 用户名、仓库名或 Pages 地址。

## 上传更新

把部署包中的以下文件上传到原仓库根目录并覆盖同名文件：

- index.html
- sw.js
- manifest.webmanifest

图标没有变化，可以不重复上传。

## 更新后

等待 GitHub Pages 部署完成，重新打开原网址。若仍显示旧版，彻底关闭桌面应用/Edge 后再打开，或刷新两次。

## 数据安全

- APP_ID、IndexedDB 名称和 localStorage 镜像键均未改变，因此同一网址下原账目和家务会继续读取。
- 旧数据首次由新版打开时会自动补上 brain.sudoku 字段。
- 升级代码不会清空数据库，但升级前仍必须下载外部 JSON 备份。

## 数独功能

- 简单、中等、困难
- 随机生成且保留唯一解
- 检查、提示、暂停、重置
- 自动保存当前进度
- 记录完成次数、最佳用时和最近20次成绩
